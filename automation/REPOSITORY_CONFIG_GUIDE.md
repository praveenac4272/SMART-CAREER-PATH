# Repository Configuration Guide

## Step-by-Step Repository Setup

1. **Initialize Git in your local folder**:
   ```bash
   git init
   ```

2. **Add Remote Origin**:
   ```bash
   git remote add origin https://github.com/praveenac4272/SMART-CAREER-PATH.git
   ```

3. **Stage All Files**:
   ```bash
   git add .
   ```

4. **Commit Changes**:
   ```bash
   git commit -m "feat: setup enterprise Appium E2E framework, 400+ test cases, reports and CI/CD pipeline"
   ```

5. **Push to Remote Repository**:
   ```bash
   git branch -M main
   git push -u origin main
   ```
