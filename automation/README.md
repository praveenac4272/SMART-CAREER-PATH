# SMART CAREER PATH - Enterprise Appium E2E Automation Framework

Welcome to the **SMART CAREER PATH** enterprise-grade mobile test automation framework.

## Key Features
- **400+ Executable Appium Test Cases** across 20 functional modules.
- **Multi-Format Report Generator**: Excel (`.xlsx`), HTML (`execution-report.html`, `dashboard.html`), JSON, and Markdown.
- **Automated CI/CD Pipeline**: Integrated GitHub Actions workflow running on Android Emulator (API 34).
- **GitHub Pages Reporting**: Automated publishing of execution dashboards to GitHub Pages.

## Directory Structure
```
automation/
├── pages/         # Page Object Model (POM) classes
├── tests/         # 410 Executable Test Cases
├── data/          # Test Data Engine
├── drivers/       # Appium Driver Manager
├── reports/       # Excel, HTML, JSON, Markdown Reporters
├── screenshots/   # Screenshot capture utilities
├── logs/          # Logging engine
├── config/        # Environment & Appium Capabilities
├── utils/         # Touch & Gesture Utilities
├── listeners/     # Test Lifecycle Listener & Retry Manager
└── runners/       # Main Test Suite Runner CLI
```
